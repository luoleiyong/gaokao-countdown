# 高考倒计时 · 每日幸运签

一款面向高中生与教师的 Windows 桌面小工具：高考倒计时、每日幸运签、学科知识签、二十四节气签、桌面宠物、天气详情，以及课堂随机点名与课程表。

应用常驻系统托盘，可贴在桌面层作为宠物显示；所有数据保存在本机，不依赖账号与云服务。

## 功能特性

### 倒计时与每日签
- 高考日期可自定义，精确倒计时到秒，展示备考进度
- 每日一签（共 280 签），按倒计时天数落签，每天仅可开启一次
- 上上签 / 上签 / 中签 / 静心签多档签文，支持保存为图片
- 学科知识签独立窗口，十门学科中最多选择 6 科
- 二十四节气签，节气当天自动切换
- 签运簿记录历史签文，可回看

### 桌面宠物与天气
- 一键切换桌面宠物模式，窗口贴在桌面层，不遮挡其他程序
- 宠物大小可调，支持四套皮肤：黑板粉笔、星河夜航、晨光纸卷、青竹小院
- 今日天气卡片与未来三天预报，点击查看天气详情与出行建议
- 天气数据优先使用中国天气网，自动定位城市，异常时切换备用数据源

### 课堂助手（随机点名 + 课程表）
- **多名单管理**：一个名单对应一个班级/一次点名，点击左侧名单即可切换
- **多种导入方式**：支持拖拽或选择 `.txt`、`.csv`、`.xlsx`、`.xls` 文件导入名单，可一次导入多个
- **随机点名**：大字展示被点到的学生，点击一次抽取一人；点名主页不显示已抽人数与剩余人数
- **管理员模式**：需要密码进入，首次使用自行设置密码（至少 4 位）
  - 修改名单名称、删除名单
  - 修改学生姓名、批量添加学生
  - 查看每位学生被抽中的次数、一键重置次数
  - 为每位学生单独设置抽取权重（0.1 – 10），权重越高越容易被抽到
  - 调试模式（预览每日首抽动画）已迁移至管理员模式
- **课程表**：周一至周日 × 多节课的表格，节次与时间描述均可编辑，自动保存
  - 支持一键导入：可粘贴表格文本，或选择 `.csv` / `.txt` / `.xlsx` 文件
  - 支持增加、删除节次

## 下载与安装

前往仓库的 **Releases** 页面下载最新的便携版：

1. 下载 `GaokaoCountdown-*-portable.exe`
2. 双击直接运行，无需安装
3. 首次运行会在系统托盘常驻，右下角托盘图标可打开主界面或退出

> 若 GitHub 下载缓慢，可在应用内点击“下载新版本”，程序会自动选择国内加速镜像。

## 使用说明

### 名单导入格式

- **txt**：每行一个姓名，也支持用逗号、空格、分号分隔
- **csv / xlsx**：自动识别“姓名 / 学生姓名 / name”列；没有表头时自动选择中文姓名最多的一列
- 自动过滤空行、序号、表头等无关内容，并自动去重

### 名单文件示例

```text
姓名
张三
李四
王五
```

```text
张三,李四,王五
```

### 管理员模式

1. 打开「课堂助手」→ 右上角「管理员」
2. 首次进入时设置密码，之后每次进入都需要验证
3. 在管理员面板中管理名单、学生、权重、抽取次数与调试开关
4. 密码仅保存在本机配置文件中（加盐哈希），不会上传

### 课程表导入格式

表格格式（第一行包含星期）：

```text
节次,时间,周一,周二,周三,周四,周五
第1节,08:00-08:45,语文,数学,英语,物理,化学
第2节,08:55-09:40,数学,语文,物理,化学,英语
```

逐行格式：

```text
周一 第1节 08:00-08:45 语文
周二 第2节 08:55-09:40 数学
```

也可以直接在课程表页面点击单元格编辑，修改会自动保存。

## 版本更新

- 应用启动后会自动检测更新，此后每 6 小时静默检查一次
- 更新源固定为项目仓库的 Latest Release，无需手动填写地址
- GitHub API 不可达时，会通过 jsDelivr CDN 读取版本清单
- 下载新版本时优先使用国内加速镜像（ghproxy.net / gh-proxy.com / ghfast.top），自动探测可用线路
- 发布新版本只需：更新版本号 → 打包 → 创建 Release 并上传 exe

## 开发与构建

环境要求：Windows、Node.js 18+。

```bash
# 安装依赖
npm install

# 本地运行
npm start

# 打包便携版
npx electron-builder --win portable
```

构建产物位于 `dist/` 目录。

### 目录结构

```text
main.js               主进程：窗口、托盘、存储、天气、更新、课堂数据
preload.js            安全桥接（contextBridge）
renderer/
  index.html          主面板
  app.js              倒计时 / 抽签 / 天气 / 设置
  styles.css          主界面样式与四套皮肤
  knowledge.html      学科知识签
  classroom.html      课堂助手（随机点名 / 课程表）
  classroom.js        课堂点名、名单、管理员、课程表逻辑
  classroom.css       课堂助手样式
  signs.js            280 支幸运签
  solar-terms.js      二十四节气
  sound.js            音效
update/version.json   版本清单（CDN 兜底更新源）
build/icon.png        应用图标
```

## 数据与隐私

- 所有数据保存在本机用户目录下的 `GaokaoCountdown/store.json`
- 名单、抽签记录、课程表、管理员密码哈希均不会上传
- 应用仅访问天气接口与 GitHub 更新接口

## 这是什么

一个给高中生和教师用的 Windows 桌面小工具。

它把「距离高考还有多久」「今天抽一支签」「上课随机点名」「这节是什么课」放进一个常驻桌面的小窗口里，不需要打开浏览器，也不需要在多个软件之间切换。窗口可以收进桌面宠物，贴在桌面层，不挡其他程序。

不需要账号，不依赖云服务。名单、签运簿、课程表、管理员密码全部保存在本机，卸载或换机前可以一键导出备份。

## 特性

| 能力 | 说明 |
|---|---|
| **高考倒计时** | 日期可自定义，精确到秒，展示备考进度和「今日还剩」时间 |
| **重要日子** | 自行添加模考、月考、志愿填报等事件，首页展示最近 3 个与剩余天数 |
| **每日幸运签** | 280 支签按倒计时天数落签，每天一支，支持保存为图片 |
| **学科知识签** | 十门学科最多选 6 科，主窗口内打开，左上角返回 |
| **二十四节气签** | 节气当天自动切换，附节气诗句与备考建议 |
| **签运簿** | 自动记录历史签文，可回看往期 |
| **桌面宠物** | 贴在桌面层显示倒计时、今日签、天气与课程，可调大小、换皮肤 |
| **天气详情** | 实时温度、未来三天、逐小时预报与出行建议，10 分钟自动刷新 |
| **桌宠课程提醒** | 按时间显示本节课与接下来的课程（最多 3 节），当天结束后显示鼓励文案 |
| **随机点名** | 多名单管理，支持 txt / csv / xlsx / xls 拖拽导入，可一次抽多人 |
| **一轮不重复** | 同一轮内不会重复抽到同一个人，抽完自动开启新一轮 |
| **随机分组** | 按组数或每组人数随机分组，结果以分组卡片展示 |
| **课堂计时** | 1 / 3 / 5 / 10 / 15 分钟预设，支持暂停、继续、重置与结束提示音 |
| **全屏投影** | 一键进入大字投影模式，适合教室大屏，按 Esc 退出 |
| **课程表** | 周一至周日 × 多节课，支持晚自习；可粘贴或导入文件，自动保存 |
| **管理员模式** | 设置页连点版本号 5 次进入，可改名单、姓名、权重、抽取次数 |
| **自动更新** | 后台静默下载安装包，支持重启安装或退出后安装，国内镜像加速 |
| **自动备份** | 每天启动备份数据，保留最近 7 天，支持导出 / 导入迁移 |

## 快速开始

### 方式一：安装包（推荐）

1. 从 [Releases](https://github.com/luoleiyong/gaokao-countdown/releases) 下载 `GaokaoCountdown-Setup-*.exe`
2. 双击运行，阅读并同意用户协议
3. 选择安装目录，安装完成后可直接启动

安装版会创建桌面快捷方式与卸载程序，安装过程不需要管理员权限。

### 方式二：便携版

下载 `GaokaoCountdown-*-portable.exe`，双击直接运行，不写注册表，不需要安装。

> 首次运行时 Windows 可能提示「未知发布者」或浏览器提示「该程序可能有害」，这是因为安装包尚未代码签名。选择「更多信息 → 仍要运行」或「保留」即可，文件本身没有损坏。

### 方式三：源码运行

环境要求：Windows、Node.js 18+。

```bash
git clone https://github.com/luoleiyong/gaokao-countdown.git
cd gaokao-countdown
npm install
npm start
```

首次启动会弹出配置向导：设置高考日期、选择科目（最多 6 科）、是否开机自启。

## 使用说明

### 名单导入格式

- **txt**：每行一个姓名，也支持用逗号、空格、分号分隔
- **csv / xlsx**：自动识别「姓名 / 学生姓名 / name」列；没有表头时自动选择中文姓名最多的一列
- 自动过滤空行、序号、表头等无关内容，并自动去重

```text
姓名
张三
李四
王五
```

```text
张三,李四,王五
```

### 课程表格式

表格格式（第一行包含星期）：

```text
节次,时间,周一,周二,周三,周四,周五
第1节,08:00-08:45,语文,数学,英语,物理,化学
第2节,08:55-09:40,数学,语文,物理,化学,英语
```

逐行格式：

```text
周一 第1节 08:00-08:45 语文
周二 第2节 08:55-09:40 数学
```

也可以直接在课程表页面点击单元格编辑，修改会自动保存。晚自习课次可单独添加，并一键显示或隐藏。

### 管理员模式

1. 打开「设置」→ 在「版本与更新」右侧连续点击版本号 5 次
2. 首次进入时设置密码（至少 4 位），之后每次进入都需要验证
3. 在管理员面板中管理名单、学生姓名、抽取权重、抽取次数与调试开关
4. 清空签运簿后可通过「撤销清空」恢复上一次数据

密码只保存在本机配置文件中（加盐哈希），不会上传。

### 全局快捷键

| 快捷键 | 功能 |
|---|---|
| `Ctrl + Alt + K` | 打开课堂点名 |
| `Ctrl + Alt + G` | 打开主界面 |

快捷键注册失败不会影响程序其他功能。

### 关闭窗口与开机自启

- 点击主界面 `×` 会收进桌面宠物，点 `—` 隐藏到系统托盘
- 托盘图标右键可打开主界面、课堂助手、课程表或退出
- 开启开机自启后，开机时以桌面宠物形式出现，不会弹出主界面

## 自动更新

- 启动后自动检测更新，此后每 6 小时静默检查一次，可在设置中关闭
- 更新源固定为项目仓库的 Latest Release，无需手动填写地址
- 发现新版本后在首页推送更新公告，可选择「现在更新」或「稍后」
- 开启自动下载后会在后台静默下载安装包，设置页与首页同步显示进度
- 下载完成可选择「重启更新」立即安装，或「稍后更新」在退出程序后自动安装
- 下载与检测优先使用国内加速镜像（gh-proxy.com / ghproxy.net），GitHub API 不可达时自动切换镜像或 jsDelivr CDN
- v1.7.1 起：临时目录不可写时自动回退到系统下载目录或数据目录；下载失败时设置页提供「手动下载安装包」入口，不再弹出阻塞式错误框

## 数据与备份

- 所有数据保存在本机：`%APPDATA%\GaokaoCountdown\store.json`
- 名单、签运簿、课程表、管理员密码哈希均不会上传
- 应用仅访问天气接口与 GitHub 更新接口
- 每天首次启动自动备份到 `GaokaoCountdown\backups\`，保留最近 7 天
- 设置页「数据与备份」可开关自动备份，并进行「导出数据」「导入数据」
- 导出的 JSON 包含倒计时日期、签运簿、名单、课程表、重要日子与偏好设置

## 启动日志

- 每次启动与关键操作会写入程序同目录下的 `启动日志.txt`（便携版写在便携版 exe 所在目录）
- 每行包含本地时间戳与中文事件描述，便于排查启动、点名、更新等问题
- 若程序目录不可写，会自动回退到用户数据目录 `GaokaoCountdown\启动日志.txt`

## 常见问题

**Q：浏览器提示「该程序有害」，无法下载怎么办？**

安装包没有代码签名，Chrome / Edge 的安全拦截会误判。在下载列表里选择「保留」或「仍要下载」；运行时的 Windows SmartScreen 提示选择「更多信息 → 仍要运行」。

**Q：自动更新失败，提示写入目录失败？**

v1.7.1 起会自动回退到系统下载目录或数据目录重试。如果仍失败，通常是杀毒软件拦截了临时目录，可在设置页点击「手动下载安装包」前往 Releases 下载。

**Q：桌宠没有显示课程？**

确认课程表里对应星期、节次的科目和时间都已填写，时间格式需包含起止时间，例如 `08:00-08:45`。课程表编辑后返回主界面即可生效。

**Q：换电脑后名单和签运簿还在吗？**

不在。请在旧电脑「设置 → 数据与备份」导出 JSON，在新电脑导入即可恢复名单、课程表、签运簿与设置。

**Q：导入名单没有识别到姓名？**

检查文件是否为空、编码是否为 UTF-8；xlsx 建议把姓名放在一列并保留「姓名」表头。也可以直接把文件拖到课堂助手的名单区域。

**Q：忘记管理员密码了？**

密码只保存在本机。可以关闭程序后备份并删除 `%APPDATA%\GaokaoCountdown\store.json` 中的 `passwordHash` 与 `passwordSalt` 字段，再重新设置；名单等数据会保留。

**Q：关闭窗口后程序去哪了？**

点击 `×` 会收进桌面宠物，点击 `—` 会隐藏到系统托盘。右键托盘图标可以重新打开或退出程序。

**Q：天气城市不对？**

在设置中填写中文城市名（如「杭州」）或中国天气网城市代码；留空则自动定位。同名地点可在设置里手动指定。

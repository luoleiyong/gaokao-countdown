## 这是什么

一个给高中生和教师用的 Windows 桌面小工具。

它把「距离高考还有多久」「今天抽一支签」「上课随机点名」「这节是什么课」放进一个常驻桌面的小窗口里，不需要打开浏览器，也不需要在多个软件之间切换。窗口可以收进桌面宠物，贴在桌面层，不挡其他程序。

不需要账号，不依赖云服务。名单、签运簿、课程表、管理员密码全部保存在本机，卸载或换机前可以一键导出备份。

## 快速开始

### 方式一：安装包（推荐）

1. 从 [Releases](https://github.com/luoleiyong/gaokao-countdown/releases) 下载 `GaokaoCountdown-Setup-*.exe`
2. 双击运行，阅读并同意用户协议
3. 选择安装目录，安装完成后可直接启动

安装版会创建桌面快捷方式与卸载程序，安装过程不需要管理员权限。

### 方式二：便携版

下载 `GaokaoCountdown-*-portable.exe`，双击直接运行，不写注册表，不需要安装。

> 首次运行时 Windows 可能提示「未知发布者」或浏览器提示「该程序可能有害」，这是因为安装包尚未代码签名。选择「更多信息 → 仍要运行」或「保留」即可，文件本身没有损坏。

### 方式三：源码运行

环境要求：Windows、Node.js 18+。

```bash
git clone https://github.com/luoleiyong/gaokao-countdown.git
cd gaokao-countdown
npm install
npm start
```

首次启动会弹出配置向导：设置高考日期、选择科目（最多 6 科）、是否开机自启。

## 使用说明

### 名单导入格式

- **txt**：每行一个姓名，也支持用逗号、空格、分号分隔
- **csv / xlsx**：自动识别「姓名 / 学生姓名 / name」列；没有表头时自动选择中文姓名最多的一列
- 自动过滤空行、序号、表头等无关内容，并自动去重

```text
姓名
张三
李四
王五
```

```text
张三,李四,王五
```

### 课程表格式

表格格式（第一行包含星期）：

```text
节次,时间,周一,周二,周三,周四,周五
第1节,08:00-08:45,语文,数学,英语,物理,化学
第2节,08:55-09:40,数学,语文,物理,化学,英语
```

逐行格式：

```text
周一 第1节 08:00-08:45 语文
周二 第2节 08:55-09:40 数学
```

也可以直接在课程表页面点击单元格编辑，修改会自动保存。晚自习课次可单独添加，并一键显示或隐藏。

### 周末作息

很多学校的周六、周日作息与工作日不同，课程表页面右上角勾选「周末作息」后，工作日与周末会分成两张表显示：

- 工作日表只显示周一至周五
- 周末表分别填写周六、周日的时间和课程，时间用时间选择器选择，不用手动输入
- 顶部会显示「已启用周末作息」标识

周末课程有两种模式：

**课程固定（默认）**

每周六、周日的课程都一样时使用。在周末表里填写一次，之后每周自动重复。

```text
节次,周六时间,周日时间,周六课程,周日课程
第1节,08:20-09:00,08:20-09:00,语文,数学
第5节,14:10-14:50,14:10-14:50,物理,黄金周末
```

**课程不固定**

周末课程按日期变化时使用。勾选「周末课程不固定」后，可以按「日期、节次、时间、课程」导入，一次导入整个学期，程序到对应日期自动显示当天课程。

```text
日期,节次,时间,课程
2026-11-14,第1节,08:20-09:00,语文
2026-11-14,第2节,09:10-09:50,数学
2026-11-15,第5节,14:10-14:50,黄金周末
```

- 有登记的日期使用登记课程，没有登记的日期回退到「课程固定」的作息
- 某天只有前几节有课、后面放假时，只登记有课的节次即可，程序会自动把后面的节次按放假处理（例如周日只上 4 节，第 5 节起显示假期）
- 周末课程按日期登记，每周自动显示当周周末的安排，不需要每周手动改表
- 导入工作日表格时，如果同一个 xlsx 带有「周末固定作息」工作表，会自动一起导入并启用周末作息
- 课程表右上角的「导入技巧」里内置了给 AI 用的整理提示词，可以一键复制，连同课程表图片发给任意 AI，让它输出本文要求的 CSV / xlsx 格式

**放假关键词**

在周末课程格填写「放假 / 假期 / 休息 / 黄金周末 / 黄金周 / 不上课 / 停课」等关键词，从这一节起按放假处理，首页课程卡与桌面宠物会显示「假期愉快」。

如果放假只放半天（例如下午放假、晚上返校晚自习），只要在后面的节次重新填写具体课程（如晚自习填「数学」），从那一节起就会恢复上课，不再显示「假」标识。

### 桌宠大肥鱼

桌面宠物顶部边框外有一只大肥鱼，会跟着课程节奏活动：

- **上课时**：播放 AI 生成的 Q 版大肥鱼奔跑动画（透明背景 WebM），沿顶部边框从左向右移动，位置对应本节课的进度，跑到最右边时刚好下课；下一节课开始后重新从左边出发。偶尔会停下来播放伸懒腰、打哈欠或吃 Token 的完整动画，结束后继续跑。动画未加载时自动回退为静态立绘 + CSS 跑步。同时冒出学生时代的碎碎念气泡，内置 250+ 条。
- **课间 / 还没上课**：播放参考项目的待机呼吸动画，并随机触发伸懒腰、打哈欠、吃 Token 的真实动画片段，每段约 10 秒；说完台词自动回落到待机呼吸。
- **今日课程结束后**：移动到顶部中间，播放 AI 生成的写作业逐帧动画，坐在小课桌前写字；气泡说到「伸懒腰、喝水、揉眼睛、吃零食、收拾桌面、看窗外、打气」等台词时，会播放对应的动作，播完继续写作业。气泡改为鼓励内容，内置 120 条，每隔几分钟换一句。
- **互动**：点鱼的头、身体或尾巴会触发不同反应——摸头、戳一戳、碰尾巴各有专属小动画和台词（各 30 条），带 1.2 秒冷却，不会连点刷屏；台词按乱序抽完再重新洗牌，一轮内不重复。
- 气泡显示约 9 秒后自动收起，不会一直挡住界面。
- **整体随缩放变化**：调整宠物大小时，倒计时、签文、课程文字、大肥鱼和气泡会一起放大或缩小；签文区域已收紧，减少上下空白，卡片更紧凑。

实现方式：角色素材为 `renderer/assets/feiyu-body.png` 全身立绘、`renderer/assets/feiyu-run.webm` 跑步动画（VP9 带 alpha 通道，24fps，174×200，2 秒无缝循环）、写作业逐帧动画（`renderer/assets/hw/` 下 169 张无损 WebP，24fps，206×200，由 canvas 播放）、写作业互动动作（`renderer/assets/hwact/` 下 7 组、每组 121 张无损 WebP），以及待机用的 `feiyu-idle.webm`、`feiyu-stretch.webm`、`feiyu-yawn.webm`、`feiyu-eat.webm`（24fps，177×200）；`renderer/fish.js` 保存台词，`renderer/app.js` 的 `renderFish()` 每秒根据 `coursePlan()` 计算当前状态与课堂进度，切换视频、更新鱼的位置与气泡；写作业用逐帧 canvas 避免视频 alpha 边缘的绿色闪烁，台词命中动作时在 canvas 上播放对应片段，上课和课间按参考项目的节奏播放完整待机动画片段，不依赖外部网络或运行时插件。

> 大肥鱼形象参考并使用 [TreapGoGo/deepseek-whale-girl](https://github.com/TreapGoGo/deepseek-whale-girl)（MIT License）中的鲸鱼娘全身立绘素材；待机呼吸、伸懒腰、打哈欠、吃 Token 的动画素材来自 [PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet)（MIT License），经 [QCYTSN/dsh-dafeiyu](https://github.com/QCYTSN/dsh-dafeiyu) 整理；跑步与写作业动画通过 AI 视频生成后抠像压缩，气泡与交互为本项目实现。

### 管理员模式

1. 打开「设置」→ 在「版本与更新」右侧连续点击版本号 5 次
2. 首次进入时设置密码（至少 4 位），之后每次进入都需要验证
3. 在管理员面板中管理名单、学生姓名、抽取权重、抽取次数与调试开关
4. 清空签运簿后可通过「撤销清空」恢复上一次数据

密码只保存在本机配置文件中（加盐哈希），不会上传。

## 自动更新

- 启动后自动检测更新，此后每 6 小时静默检查一次，可在设置中关闭
- 更新源固定为项目仓库的 Latest Release，无需手动填写地址
- 发现新版本后弹窗展示本次更新内容，可选择「现在更新」或「稍后」
- 开启自动下载后会在后台静默下载安装包，弹窗与设置页同步显示进度
- 下载完成弹出提示，点击「重启更新」后自动静默安装并重新打开程序，无需手动点击安装向导
- 选择「稍后更新」会在退出程序时自动静默安装，安装完成后自动启动新版本
- 下载与检测优先使用国内加速镜像（gh-proxy.com / ghproxy.net），GitHub API 不可达时自动切换镜像或 jsDelivr CDN
- v1.7.7 起：安装包下载改为 **GitHub 直连优先**，直连失败或超时才切换镜像；支持 Range 分片并发（4~8 个连接）与自动续传，不支持分片的服务器自动退回单连接；25 秒无数据会重试并切换地址
- v1.7.1 起：临时目录不可写时自动回退到系统下载目录或数据目录；下载失败时设置页提供「手动下载安装包」入口，不再弹出阻塞式错误框

## 数据与备份

- 所有数据保存在本机：`%APPDATA%\GaokaoCountdown\store.json`
- 名单、签运簿、课程表、管理员密码哈希均不会上传
- 应用仅访问天气接口与 GitHub 更新接口
- 每天首次启动自动备份到 `GaokaoCountdown\backups\`，保留最近 7 天
- 设置页「数据与备份」可开关自动备份，并进行「导出数据」「导入数据」
- 导出的 JSON 包含倒计时日期、签运簿、名单、课程表、重要日子与偏好设置

## 启动日志

- 每次启动与关键操作会写入程序同目录下的 `启动日志.txt`（便携版写在便携版 exe 所在目录）
- 每行包含本地时间戳与中文事件描述，便于排查启动、点名、更新等问题
- 若程序目录不可写，会自动回退到用户数据目录 `GaokaoCountdown\启动日志.txt`

## 常见问题

**Q：浏览器提示「该程序有害」，无法下载怎么办？**

安装包没有代码签名，Chrome / Edge 的安全拦截会误判。在下载列表里选择「保留」或「仍要下载」；运行时的 Windows SmartScreen 提示选择「更多信息 → 仍要运行」。

**Q：自动更新失败，提示写入目录失败？**

v1.7.1 起会自动回退到系统下载目录或数据目录重试。如果仍失败，通常是杀毒软件拦截了临时目录，可在设置页点击「手动下载安装包」前往 Releases 下载。

**Q：桌宠没有显示课程？**

确认课程表里对应星期、节次的科目和时间都已填写，时间格式需包含起止时间，例如 `08:00-08:45`。课程表编辑后返回主界面即可生效。

**Q：换电脑后名单和签运簿还在吗？**

不在。请在旧电脑「设置 → 数据与备份」导出 JSON，在新电脑导入即可恢复名单、课程表、签运簿与设置。

**Q：导入名单没有识别到姓名？**

检查文件是否为空、编码是否为 UTF-8；xlsx 建议把姓名放在一列并保留「姓名」表头。也可以直接把文件拖到课堂助手的名单区域。

**Q：忘记管理员密码了？**

密码只保存在本机。可以关闭程序后备份并删除 `%APPDATA%\GaokaoCountdown\store.json` 中的 `passwordHash` 与 `passwordSalt` 字段，再重新设置；名单等数据会保留。

**Q：关闭窗口后程序去哪了？**

点击 `×` 会收进桌面宠物，点击 `—` 会隐藏到系统托盘。右键托盘图标可以重新打开或退出程序。

**Q：天气城市不对？**

在设置中填写中文城市名（如「杭州」）或中国天气网城市代码；留空则自动定位。同名地点可在设置里手动指定。

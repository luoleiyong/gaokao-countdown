## 这是什么

一个给高中生和教师用的 Windows 桌面小工具。

它把「距离高考还有多久」「今天抽一支签」「上课随机点名」「这节是什么课」放进一个常驻桌面的小窗口里，不需要打开浏览器，也不需要在多个软件之间切换。窗口可以收进桌面宠物，贴在桌面层，不挡其他程序。

不需要账号，不依赖云服务。名单、签运簿、课程表、管理员密码全部保存在本机，卸载或换机前可以一键导出备份。

## 快速开始

### 方式一：安装包（推荐）

1. 从 [Releases](https://github.com/luoleiyong/gaokao-countdown/releases) 下载 `GaokaoCountdown-Setup-*.exe`
2. 双击运行，阅读并同意用户协议
3. 选择安装目录
4. （可选）在「数据备份位置」页选择备份文件夹；留空则使用默认位置，安装完成后在设置里也能随时修改
5. 安装完成后可直接启动

安装版会创建桌面快捷方式与卸载程序，安装过程不需要管理员权限。

### 方式二：便携版

下载 `GaokaoCountdown-*-portable.exe`，双击直接运行，不写注册表，不需要安装。

> 首次运行时 Windows 可能提示「未知发布者」或浏览器提示「该程序可能有害」，这是因为安装包尚未代码签名。选择「更多信息 → 仍要运行」或「保留」即可，文件本身没有损坏。

### 方式三：源码运行

环境要求：Windows、Node.js 18+。

```bash
git clone https://github.com/luoleiyong/gaokao-countdown.git
cd gaokao-countdown
npm install
npm start
```

首次启动会弹出配置向导：设置高考日期、选择科目（最多 6 科）、是否开机自启。

## 使用说明

### 名单导入格式

- **txt**：每行一个姓名，也支持用逗号、空格、分号分隔
- **csv / xlsx**：自动识别「姓名 / 学生姓名 / name」列；没有表头时自动选择中文姓名最多的一列
- 自动过滤空行、序号、表头等无关内容，并自动去重

```text
姓名
张三
李四
王五
```

```text
张三,李四,王五
```

### 新建名单

1. 在课堂助手左侧点「＋ 新建名单」，输入名单名称（与已有名单重名会被拦下），点「下一步：添加学生」
2. 粘贴或输入姓名，每行一个，也支持逗号、顿号分隔；中文、字母、纯数字（学号 / 座位号）都能识别，输入框下方会实时显示识别到的人数
3. 也可以用「数字填充」：填一个数字（如 10），点「生成编号」，直接得到 1、2、3 … 10；输入框里已有内容时需要再点一次才会替换
4. 点「保存名单」建立名单，并自动设为当前名单

保存后普通界面只能查看和抽取，不能删除名单里的学生；需要删人或调整时进入管理员模式，在学生表格里操作。

### 删除名单与恢复

点名页左侧「＋ 新建名单」旁边有「删除」按钮：点开后勾选名单，再点「删除所选」即可整张删除。

- 删除的名单不会立刻消失，会放进同一个窗口下方的「最近删除」，随时点「恢复」找回来
- 删除记录保存在本机，3 天后自动清除
- 学生级别的删除仍然只在管理员模式里提供

### 课程表格式

表格格式（第一行包含星期）：

```text
节次,时间,周一,周二,周三,周四,周五
第1节,08:00-08:45,语文,数学,英语,物理,化学
第2节,08:55-09:40,数学,语文,物理,化学,英语
```

逐行格式：

```text
周一 第1节 08:00-08:45 语文
周二 第2节 08:55-09:40 数学
```

也可以直接在课程表页面点击单元格编辑，修改会自动保存。晚自习课次可单独添加，并一键显示或隐藏。

### 周末作息

很多学校的周六、周日作息与工作日不同，课程表页面右上角勾选「周末作息」后，工作日与周末会分成两张表显示：

- 工作日表只显示周一至周五
- 周末表分别填写周六、周日的时间和课程，时间用时间选择器选择，不用手动输入
- 顶部会显示「已启用周末作息」标识

周末课程有两种模式：

**课程固定（默认）**

每周六、周日的课程都一样时使用。在周末表里填写一次，之后每周自动重复。

```text
节次,周六时间,周日时间,周六课程,周日课程
第1节,08:20-09:00,08:20-09:00,语文,数学
第5节,14:10-14:50,14:10-14:50,物理,黄金周末
```

**课程不固定**

周末课程按日期变化时使用。勾选「周末课程不固定」后，可以按「日期、节次、时间、课程」导入，一次导入整个学期，程序到对应日期自动显示当天课程。

```text
日期,节次,时间,课程
2026-11-14,第1节,08:20-09:00,语文
2026-11-14,第2节,09:10-09:50,数学
2026-11-15,第5节,14:10-14:50,黄金周末
```

- 有登记的日期使用登记课程，没有登记的日期回退到「课程固定」的作息
- 某天只有前几节有课、后面放假时，只登记有课的节次即可，程序会自动把后面的节次按放假处理（例如周日只上 4 节，第 5 节起显示假期）
- 周末课程按日期登记，每周自动显示当周周末的安排，不需要每周手动改表
- 导入工作日表格时，如果同一个 xlsx 带有「周末固定作息」工作表，会自动一起导入并启用周末作息
- 课程表右上角的「导入技巧」里内置了给 AI 用的整理提示词，可以一键复制，连同课程表图片发给任意 AI，让它输出本文要求的 CSV / xlsx 格式
- 也可以点课程表右上角「AI 识图」：拖入课表照片或教务系统截图，选择工作日 / 周末目标与免费视觉模型，识别完成核对节数后一键应用；课程表图片只发给免费模型，软件不上传

**放假关键词**

在周末课程格填写「放假 / 假期 / 休息 / 黄金周末 / 黄金周 / 不上课 / 停课」等关键词，从这一节起按放假处理，首页课程卡与桌面宠物会显示「假期愉快」。

如果放假只放半天（例如下午放假、晚上返校晚自习），只要在后面的节次重新填写具体课程（如晚自习填「数学」），从那一节起就会恢复上课，不再显示「假」标识。

### 桌宠大肥鱼

桌面宠物顶部边框外有一只大肥鱼，会跟着课程节奏活动：

- **上课时**：播放 AI 生成的 Q 版大肥鱼奔跑动画（透明背景 WebM），沿顶部边框从左向右移动，位置对应本节课的进度，跑到最右边时刚好下课；下一节课开始后重新从左边出发。偶尔会停下来播放伸懒腰、打哈欠或吃 Token 的完整动画，结束后继续跑。动画未加载时自动回退为静态立绘 + CSS 跑步。同时冒出学生时代的碎碎念气泡，内置 250+ 条。
- **课间 / 还没上课**：播放参考项目的待机呼吸动画，并随机触发伸懒腰、打哈欠、吃 Token 的真实动画片段，每段约 10 秒；说完台词自动回落到待机呼吸。
- **今日课程结束后**：移动到顶部中间，播放 AI 生成的写作业逐帧动画，坐在小课桌前写字；气泡说到「伸懒腰、喝水、揉眼睛、思考、托腮、吃零食、肚子饿、收拾桌面、看窗外、打气」等台词时，会播放对应的动作（每段约 6 秒），播完继续写作业。所有动作的角色大小与写作业循环一致，切换时不跳变。气泡改为鼓励内容，内置 150+ 条，并按设置中勾选的科目补充知识点提醒，每隔几分钟换一句。
- **互动**：点鱼的头、身体或尾巴会触发不同反应——摸头、戳一戳、碰尾巴各有专属小动画和台词（各 30 条），带 1.2 秒冷却，不会连点刷屏；台词按乱序抽完再重新洗牌，一轮内不重复。
- 气泡显示约 9 秒后自动收起，不会一直挡住界面。
- **整体随缩放变化**：调整宠物大小时，倒计时、签文、课程文字、大肥鱼和气泡会一起放大或缩小；签文区域已收紧，减少上下空白，卡片更紧凑。

实现方式：角色素材为 `renderer/assets/feiyu-body.png` 全身立绘、`renderer/assets/feiyu-run.webm` 跑步动画（VP9 带 alpha 通道，24fps，174×200，2 秒无缝循环）、写作业逐帧动画（`renderer/assets/hw/` 下 169 张无损 WebP，24fps，270×262，由 canvas 播放）、写作业互动动作（`renderer/assets/hwact/` 下 11 组、每组 121 张无损 WebP，270×262，20fps 播放），以及待机用的 `feiyu-idle.webm`、`feiyu-stretch.webm`、`feiyu-yawn.webm`、`feiyu-eat.webm`（24fps，177×200）；`renderer/fish.js` 保存台词，`renderer/app.js` 的 `renderFish()` 每秒根据 `coursePlan()` 计算当前状态与课堂进度，切换视频、更新鱼的位置与气泡；写作业用逐帧 canvas 避免视频 alpha 边缘的绿色闪烁，台词命中动作时在 canvas 上播放对应片段，上课和课间按参考项目的节奏播放完整待机动画片段，不依赖外部网络或运行时插件。

动作素材的抠像参数、逐帧方案与台词绑定逻辑都写在渲染层代码的注释里。

> 大肥鱼形象参考并使用 [TreapGoGo/deepseek-whale-girl](https://github.com/TreapGoGo/deepseek-whale-girl)（MIT License）中的鲸鱼娘全身立绘素材；待机呼吸、伸懒腰、打哈欠、吃 Token 的动画素材来自 [PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet)（MIT License），经 [QCYTSN/dsh-dafeiyu](https://github.com/QCYTSN/dsh-dafeiyu) 整理；跑步与写作业动画通过 AI 视频生成后抠像压缩，气泡与交互为本项目实现。

### 管理员模式

1. 打开「设置」→ 在「版本与更新」右侧连续点击版本号 5 次
2. 首次进入时设置密码（至少 4 位），之后每次进入都需要验证
3. 在管理员面板中管理名单、学生姓名、抽取权重、抽取次数与调试开关；普通界面保存的名单只能在这里删除学生，整张名单也可以在这里永久删除（点名页的「删除」则会先放进最近删除，3 天内可恢复）
4. 清空签运簿后可通过「撤销清空」恢复上一次数据

密码只保存在本机配置文件中（加盐哈希），不会上传。

### 管理员免密工具（admin-tool）

仓库里的 `admin-tool/` 是一个独立的本地小工具，用来临时跳过管理员密码，方便自己的机器上快速改名单、改权重或做调试。

| 文件 | 作用 |
|---|---|
| `admin-tool/GaokaoAdminTool.exe` | **双击即用**：启动后自动写入 1 分钟票据并打开主程序的管理员模式，不用装 Node.js |
| `admin-tool/GaokaoAdminTool.cs` | 上面那个 exe 的源码（C# WinForms，编译：`csc /target:winexe /win32icon:admin-tool\app.ico /out:admin-tool\GaokaoAdminTool.exe admin-tool\GaokaoAdminTool.cs`） |
| `admin-tool/admin-unlock-ui.js` | 图形界面版：启动一个只监听 127.0.0.1 的本地页面，按钮式开启 / 收回免密 |
| `admin-tool/admin-unlock-ui.html` | 上面那个页面的界面文件（与 js 放在同一目录） |
| `admin-tool/admin-unlock-ui.cmd` | 双击启动入口：有 Node.js 就用 Node，没有就用已打包的应用以 `ELECTRON_RUN_AS_NODE` 方式运行同一脚本 |
| `admin-tool/admin-unlock.js` | 命令行版：默认 1 分钟，`--minutes N` 指定时长、`--status` 看剩余、`--lock` 立即收回 |
| `admin-tool/admin-unlock-core.js` | 两个版本共用的读写逻辑 |

用法：

```bash
# exe 版：双击 admin-tool\GaokaoAdminTool.exe，启动后自动打开主程序的管理员模式
# 也支持无界面参数：--minutes N 开票、--lock 收回、--status 看状态

# 界面版（会自动打开浏览器）
node admin-tool/admin-unlock-ui.js

# 命令行版：默认开 1 分钟免密
node admin-tool/admin-unlock.js

# 想开久一点就自己指定分钟数
node admin-tool/admin-unlock.js --minutes 30
```

Windows 上直接双击 `admin-tool/admin-unlock-ui.cmd` 也可以，不需要手动敲命令。

原理与代码位置：

- 工具往 `%APPDATA%\GaokaoCountdown\admin-unlock.json` 写一张带 `expires` 的票据
- 主进程读票据并决定是否放行：`main.js:20`（`ADMIN_TICKET_FILE`）、`main.js:805`（`adminTicketFresh`）、`main.js:4919`（`adminGuard`）
- 管理员入口三处判定：`main.js:4960`（`classroom:admin-status`）、`main.js:4994`（`classroom:admin-login`）、`main.js:4976`（`classroom:admin-setup`）
- 自动开管理员：exe 启动主程序时带 `--admin`，主程序在 `main.js:5416`（第二个实例）与 `main.js:5454`（首次启动）里调用 `openClassroomWindow({ admin: true })`
- 票据过期或被 `--lock` 收回后，进入管理员模式立刻恢复密码验证，不需要重启应用
- 工具只做「开票 / 收回 / 看状态」，不读写 `store.json`，也不改管理员密码

票据默认只开 1 分钟：够进管理员面板改完一次设置，超时自动恢复密码验证。工具本身不提供修改管理员密码的功能。

非 VIP 限次：免密进入的管理员会话，**一天只能改一名学生的权重**。改成功那一刻起额度就记在 `%APPDATA%\GaokaoCountdown\admin-quota.json`，同一名学生可以继续微调，换其他人会被 `main.js:5160` 的 `classroom:update-name` 拦下并提示「请稍后重试（非VIP用户仅限一人使用）。请次日再试」；管理员面板里其他人的权重输入框直接置灰（`renderer/classroom.js:646` 与 `renderer/classroom.js:670`，横幅样式在 `renderer/classroom.css:1220`）。用密码登录的管理员会话不受这条限制；免密会话被限额后，管理员面板里会出现「兑换码」输入框，兑换成功后权重不限次数（`main.js` 的 `classroom:vip-redeem`，凭据落在 `%APPDATA%\GaokaoCountdown\vip.json`）。

这个目录不会被打包进发布版（`package.json` 的 `build` 没有把它列进 `files` 或 `extraResources`），只在本机仓库里使用；票据文件同样只在本机，带过期时间。

## 常见问题

**Q：浏览器提示「该程序有害」，无法下载怎么办？**

安装包没有代码签名，Chrome / Edge 的安全拦截会误判。在下载列表里选择「保留」或「仍要下载」；运行时的 Windows SmartScreen 提示选择「更多信息 → 仍要运行」。

**Q：自动更新失败，提示写入目录失败？**

v1.7.1 起会自动回退到系统下载目录或数据目录重试。如果仍失败，通常是杀毒软件拦截了临时目录，可在设置页点击「手动下载安装包」前往 Releases 下载。

**Q：桌宠没有显示课程？**

确认课程表里对应星期、节次的科目和时间都已填写，时间格式需包含起止时间，例如 `08:00-08:45`。课程表编辑后返回主界面即可生效。

**Q：换电脑后名单和签运簿还在吗？**

不在。请在旧电脑「设置 → 数据与备份」导出 JSON，在新电脑导入即可恢复名单、课程表、签运簿与设置。

**Q：导入名单没有识别到姓名？**

检查文件是否为空、编码是否为 UTF-8；xlsx 建议把姓名放在一列并保留「姓名」表头。也可以直接把文件拖到课堂助手的名单区域。

**Q：忘记管理员密码了？**

密码只保存在本机。可以关闭程序后备份并删除 `%APPDATA%\GaokaoCountdown\store.json` 中的 `passwordHash` 与 `passwordSalt` 字段，再重新设置；名单等数据会保留。

**Q：备份文件存在哪里？可以换位置吗？**

默认在 `%APPDATA%\GaokaoCountdown\backups\`。打开「设置 → 数据与备份 → 备份位置」，点「选择文件夹」选中新目录即可，程序会立刻把当前数据备份过去；装在网盘同步目录里等于多一份异地副本。「恢复默认」可以回到默认目录。安装时也可以在「数据备份位置」页预先指定。

**Q：关闭窗口后程序去哪了？**

点击 `×` 会收进桌面宠物。右键托盘图标可以重新打开或退出程序。

**Q：天气城市不对？**

在设置中填写中文城市名（如「杭州」）或中国天气网城市代码；留空则自动定位。同名地点可在设置里手动指定。

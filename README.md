# 高考倒计时 · 每日幸运签

一款面向高中生与教师的 Windows 桌面小工具：高考倒计时、每日幸运签、学科知识签、二十四节气签、桌面宠物、天气详情，以及课堂随机点名与课程表。

应用常驻系统托盘，可贴在桌面层作为宠物显示；所有数据保存在本机，不依赖账号与云服务。

## 功能特性

### 倒计时与每日签
- 高考日期可自定义，精确倒计时到秒，展示备考进度
- 每日一签（共 280 签），按倒计时天数落签，每天仅可开启一次
- 上上签 / 上签 / 中签 / 静心签多档签文，支持保存为图片
- 学科知识签（主窗口内打开，左上角返回，不会多开窗口），十门学科中最多选择 6 科
- 二十四节气签，节气当天自动切换
- 签运簿记录历史签文，可回看

### 桌面宠物与天气
- 一键切换桌面宠物模式，窗口贴在桌面层，不遮挡其他程序
- 宠物大小可调，支持四套皮肤：黑板粉笔、星河夜航、晨光纸卷、青竹小院
- 天气卡片展示当前时段的实时温度与未来三天预报，10 分钟自动刷新
- 点击天气卡片查看逐小时预报（未来 24 小时、降水概率）、三天详情与出行建议
- 天气数据优先使用中国天气网，逐小时预报使用 Open-Meteo，自动定位城市

### 课堂助手（随机点名 + 课程表）
- **多名单管理**：一个名单对应一个班级/一次点名，点击左侧名单即可切换
- **多种导入方式**：支持拖拽或选择 `.txt`、`.csv`、`.xlsx`、`.xls` 文件导入名单，可一次导入多个
- **随机点名**：大字展示被点到的学生，点击一次抽取一人；点名主页不显示已抽人数与剩余人数
- **多人抽取**：点名区可增减抽取人数（1 至名单人数），一次抽出多名学生且不重复
- **单窗口体验**：课堂点名在主窗口内打开，左上角「返回」回到主界面，不会多开窗口
- **点名音效与姓名朗读**：点名过程带摇签音效，落地提示音；可开关中文姓名朗读
- **管理员模式**：在设置页连续点击版本号 5 次进入，需要密码验证（首次使用自行设置，至少 4 位）
  - 修改名单名称、删除名单
  - 修改学生姓名、批量添加学生
  - 查看每位学生被抽中的次数、一键重置次数
  - 为每位学生单独设置抽取权重（0.1 – 10），权重越高越容易被抽到
  - 调试模式（预览每日首抽动画）已迁移至管理员模式
  - 清空签运簿（含误触保护：清空后可「撤销清空」恢复上次数据）
- **课程表**：周一至周日 × 多节课的表格，节次与时间描述均可编辑，自动保存
  - 支持一键导入：可粘贴表格文本，或选择 `.csv` / `.txt` / `.xlsx` 文件
  - 支持增加、删除节次

### 安装与首次配置
- 提供 NSIS 安装包，安装前展示用户协议（禁止商用、作者联系方式等），需同意后才能继续
- 安装包支持选择安装目录、创建桌面快捷方式，安装完成后可直接运行
- 首次使用会弹出配置向导：设置高考日期、选择科目（最多 6 科）、是否开机自启
- 设置页可点击作者邮箱一键复制；点击《用户协议》弹窗查看正文，取消或确定均可关闭

## 下载与安装

前往仓库的 **Releases** 页面下载：

- **安装版（推荐）**：`GaokaoCountdown-Setup-*.exe`，按向导安装，含用户协议与卸载程序
- **便携版**：`GaokaoCountdown-*-portable.exe`，双击直接运行，无需安装

安装或解压后首次运行会在系统托盘常驻，右下角托盘图标可打开主界面或退出。

> 若 GitHub 下载缓慢，应用会自动使用国内加速镜像下载新版本。

## 使用说明

### 名单导入格式

- **txt**：每行一个姓名，也支持用逗号、空格、分号分隔
- **csv / xlsx**：自动识别“姓名 / 学生姓名 / name”列；没有表头时自动选择中文姓名最多的一列
- 自动过滤空行、序号、表头等无关内容，并自动去重

### 名单文件示例

```text
姓名
张三
李四
王五
```

```text
张三,李四,王五
```

### 管理员模式

1. 打开「设置」→ 在“版本与更新”右侧连续点击版本号 5 次
2. 首次进入时设置密码，之后每次进入都需要验证
3. 在管理员面板中管理名单、学生、权重、抽取次数与调试开关
4. 密码仅保存在本机配置文件中（加盐哈希），不会上传

### 课程表导入格式

表格格式（第一行包含星期）：

```text
节次,时间,周一,周二,周三,周四,周五
第1节,08:00-08:45,语文,数学,英语,物理,化学
第2节,08:55-09:40,数学,语文,物理,化学,英语
```

逐行格式：

```text
周一 第1节 08:00-08:45 语文
周二 第2节 08:55-09:40 数学
```

也可以直接在课程表页面点击单元格编辑，修改会自动保存。

## 版本更新

- 应用启动后自动检测更新，此后每 6 小时静默检查一次，可在设置中关闭
- 更新源固定为项目仓库的 Latest Release，无需手动填写地址
- 发现新版本后在首页推送更新公告，展示本次更新内容，可选择「现在更新」或「稍后」
- 开启自动下载后会在后台静默下载安装包，设置页与首页同步显示进度
- 下载完成弹出提示，可选择「重启更新」立即安装，或「稍后更新」在退出程序后自动安装
- 设置页提供自动检测、自动下载开关与上次检查时间，类似系统更新
- 下载与检测优先使用国内加速镜像（gh-proxy.com / ghproxy.net），GitHub API 不可达时自动切换镜像或 jsDelivr CDN
- 发布新版本只需：更新版本号 → 打包安装包与便携版 → 创建 Release 并上传两个 exe

## 开发与构建

环境要求：Windows、Node.js 18+。

```bash
# 安装依赖
npm install

# 本地运行
npm start

# 打包便携版 + 安装包
npx electron-builder --win portable nsis
```

构建产物位于 `dist/` 目录，包含 `GaokaoCountdown-*-portable.exe` 与 `GaokaoCountdown-Setup-*.exe`。

### 目录结构

```text
main.js               主进程：窗口、托盘、存储、天气、更新、课堂数据
preload.js            安全桥接（contextBridge）
renderer/
  index.html          主面板
  app.js              倒计时 / 抽签 / 天气 / 设置 / 首次配置 / 更新
  styles.css          主界面样式与四套皮肤
  knowledge.html      学科知识签
  classroom.html      课堂助手（随机点名 / 课程表）
  classroom.js        课堂点名、名单、管理员、课程表逻辑
  classroom.css       课堂助手样式
  signs.js            280 支幸运签
  solar-terms.js      二十四节气
  sound.js            抽签与点名音效
update/version.json   版本清单（CDN 兜底更新源）
build/icon.png        应用图标
build/license.txt     安装包用户协议
```

## 数据与隐私

- 所有数据保存在本机用户目录下的 `GaokaoCountdown/store.json`
- 名单、抽签记录、课程表、管理员密码哈希均不会上传
- 应用仅访问天气接口与 GitHub 更新接口

## 启动日志

- 每次启动与关键操作会写入程序同目录下的 `启动日志.txt`（便携版写在便携版 exe 所在目录）
- 每行包含本地时间戳与中文事件描述，便于排查启动、点名、更新等问题
- 若程序目录不可写，会自动回退到用户数据目录 `GaokaoCountdown/启动日志.txt`
- 设置页不再展示启动日志内容

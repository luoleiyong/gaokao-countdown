# 测试版 2.1.0-test 使用说明

> 这是本地测试版，**没有发布**。正式版 2.1.1 发布后，`update/version.json` 与它保持一致；测试版只用于本地验证。

## 一、程序位置

- 便携版：`dist15-test/GaokaoCountdown-2.1.0-test-portable.exe`
- 安装版：`dist15-test/GaokaoCountdown-Setup-2.1.0-test.exe`
- 免安装目录：`dist15-test/win-unpacked/高考倒计时.exe`

测试版的版本号由构建参数 `--config.extraMetadata.version=2.1.0-test` 注入，源码 `package.json` 仍保持 2.0.7。

## 二、打开测试面板

测试面板是**独立窗口**（约 380×780，默认置顶），打开课程表、课堂助手、知识签，或进入桌面宠物模式时都不会消失。

- 测试版启动后会自动打开测试面板
- 主界面不显示测试按钮；面板关闭后按 `Ctrl + Shift + T` 可重新打开
- 面板右上角「主界面」可把主窗口叫到前面，「×」关闭面板

只有版本号包含 `-test`（或地址带 `?test=1`、本地存了 `gk-test=1`、启动参数带 `--test-mode`）时才允许打开。

## 三、面板功能对照

### 主界面 / 抽签

| 按钮 | 实际触发 |
|---|---|
| 摇签流程 | `startDrawFlow(true)` + `shakeDraw()`，强制走完整摇签动画 |
| 首次抽签 | `state.debugPreview=false; showFirstDraw(true)` |
| 调试预览首抽 | `state.debugPreview=true; showFirstDraw(true)`，不影响真实记录 |
| 节气签 | `openTermModal(true)`，随机展示一支节气签 |
| 天气详情 | `openWeatherDetail()`，打开逐小时与未来三天 |
| 重要日子 | `openEventsModal()` |
| 保存签卡 | `exportSignCard()`，弹出保存图片对话框 |
| 展开签运簿 | `state.historyExpanded=true; renderHistory()` |
| 全签彩蛋 | 清除本地 `gk-all-signs-*` 后 `maybeAllSignsEgg(0)`，展示高考当天 280 签全点亮 |

### 桌面宠物

| 按钮 | 实际触发 |
|---|---|
| 进入宠物 / 回主界面 | `bridge.setPetMode(true/false)` |
| 右键菜单 | `openPetMenu()`，验证跟随皮肤的菜单与换肤 |
| 伸懒腰 / 喝水 / 揉眼 / 思考 / 托腮 / 吃零食 / 肚子饿 / 偷吃 / 收拾 / 看窗外 / 打气 | `fishLoadHomeworkAction(key)`，逐个播放 11 组写作业动作 |
| 待机伸懒腰 / 打哈欠 / 吃 Token | `fishPlayClip()` 播放 3 段待机视频 |
| 摸头 / 戳一戳 / 碰尾巴 | 点击对应 `.pet-fish__hit--*` 热区，触发不同台词 |
| 安静 / 慢 / 快 / 极快 | 点击设置里的互动频率按钮 |

宠物模式下测试面板保持独立置顶，不会自动收起；面板按钮照常可用，主窗口内的快捷键也可以继续用。

### 独立窗口

| 按钮 | 实际触发 |
|---|---|
| 课程表 | `bridge.openTimetable()` |
| 课堂助手 | `bridge.openClassroom()` |
| 学科知识签 | `bridge.openKnowledge()` |
| 管理员模式 | `bridge.openClassroomAdmin()`，首次需设置至少 4 位密码 |
| 课堂调试抽签 | `bridge.adminTriggerDraw()`，需先在管理员模式开启「调试模式」 |

### 设置 / 更新

| 按钮 | 实际触发 |
|---|---|
| 打开设置 | `openSettings()` |
| 黑板 / 星河 / 晨光 / 青竹 | 立即换肤并保存 |
| 更新公告 | 构造一条 2.1.0-test 的假更新，调用 `showUpdateNotes()` |
| 下载完成弹窗 | 构造已下载状态，调用 `showUpdateReadyDialog()`；**不要点“现在更新”** |
| 检查更新 | 真实请求更新源，不会自动安装 |

### 工具

| 按钮 | 实际触发 |
|---|---|
| 关闭所有弹窗 | 关闭抽签、首抽、彩蛋、节气、天气、重要日子、更新、设置等 |
| 重置彩蛋记录 | 清除 `gk-all-signs-*` |
| 打开数据目录 | 提示数据目录路径（`%APPDATA%\GaokaoCountdown`） |

## 四、宠物快捷键

进入宠物模式后：

| 快捷键 | 动作 |
|---|---|
| `Alt + 1` ~ `Alt + 0`、`Alt + -` | 伸懒腰、喝水、揉眼、思考、托腮、吃零食、肚子饿、偷吃、收拾、看窗外、打气 |
| `Alt + I` | 待机伸懒腰 |
| `Alt + H` / `B` / `T` | 摸头 / 戳身体 / 碰尾巴 |
| `Alt + M` | 打开宠物右键菜单 |
| `Alt + P` | 回到主界面 |

## 六、注意事项

1. 测试版使用真实数据目录 `%APPDATA%\GaokaoCountdown`，演示前建议先在设置里导出备份。
2. 「下载完成弹窗」只是构造状态，**不要点击“现在更新”**，否则会尝试运行假路径。
3. 「全签彩蛋」只影响本地彩蛋标记，不会修改签运记录。
4. 测试版没有发布，不要用它替换正式版；正式版为 2.1.1。
5. 重新构建测试版：

```powershell
$env:ELECTRON_BUILDER_COMPRESSION_LEVEL="1"
npx electron-builder --win portable nsis `
  --config.npmRebuild=false `
  --config.compression=normal `
  --config.directories.output=dist15-test `
  --config.extraMetadata.version=2.1.0-test `
  --publish never
```
